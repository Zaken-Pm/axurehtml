# Sports Voucher · 体育投注券

营运可发放「固定金额、单次使用、限时有效」的体育投注券给会员；会员在体育单关投注时直接用券下注、不动用自己的余额。用于赛事营销（如世界杯开幕赠券）、拉新与回流，并可在后台追踪每张券的状态。

- 版本：v1
- 后台位置：积分商城 › 优惠券管理／发券审核
- 前台位置：体育 › Bet Slip／My Bets Slip
- 关联原型：前台 · 后台

> 本文件由 HTML 规格（SportsVoucher_Specs.html）转出，供 AI／开发阅读。截图档名对应规格内 `img/` 资料夹；前台原型 `SportsVoucherFront.html`、后台原型 `SportsVoucher_Backend.html`。

## 通用规则

*名词定义 · 券的生命周期 · 使用与退回 · 派彩与统计口径 · 系统开关*

#### 名词定义

| 项目 | 说明 |
|---|---|
| 体育投注券 | 后台称「体育投注券」，前台显示 `SportsVoucher`。属于「优惠券」的一个类别（与存送比例券、输返券、中奖加奖券并列）。 |
| 单次投注金额 | 券面额。用券下注的**固定金额**，会员不可修改；**整数**，币种依券的币种。 |
| 使用次数 | **一张券只能使用 1 次**，下注成功即变为「已使用」。 |
| 有效期 | 单位**小时**。自券**发放到会员账户**起算；到期未使用即作废。到期时间＝发放时间＋有效期，精确到分钟。 |
| 投注限额 | 该盘口的最小／最大投注金额，沿用现有限额来源；前台显示 `Limit {最小限额}-{最大限额}`，数值依各盘口实际限额带入（如 `Limit 1-9,999`、`Limit 200-800`）。 |
| 预约投注 | 前台按钮 `Booking`。设定预约赔率，盘口赔率匹配成功时才成交。 |

#### 券的生命周期 【新增】

流程：[发券审核通过] →（入账） [未使用] →（下注成功） [已使用] →（注单取消／作废） [恢复为未使用 有效期重新计算]

> **到期**
> - 「未使用」的券到期即变为**已过期**。
> - **体育投注页移除不显示**；My voucher 移至 `Expired`。
>
> **已使用**
> - 下注成功后即从体育投注页清单**移除不显示**。
> - My voucher 移至 `Used`。
> - 后台状态维持「已使用」，到期后也不改为「已过期」。

> 每张券在后台「优惠券记录」是**一笔记录**，状态只有三种：**未使用／已使用／已过期**（「待结算」不适用于体育投注券）。

#### 使用、退回与派彩 【新增】

| 情境 | 券 | 会员余额 |
|---|---|---|
| 用券下注，投注成功 | **变为已使用** | 不检查、不扣除 |
| 投注失败（`Betting failed`） | 仍为未使用 | 不变 |
| 赔率已变更导致失败 → 按 `Accept and bet` 重送成功 | 重送成功时变为已使用 | 不变 |
| 预约投注：送出预约 | 仍为未使用 | 不变 |
| 预约投注：预约赔率匹配成功（成交） | **成交当下变为已使用** | 不变 |
| 预约投注：成交当下券已过期或已使用 | 不变；**此预约单状态变更为失败**（注单页 Expired · `Booking failed`） | 不变 |
| 预约投注：未成交、取消 | 仍为未使用 | 不变 |
| 已成交的用券注单被取消／作废（Void、赛事取消等） | **退回次数：原券恢复为未使用**（同一张券、券 ID 不变），**有效期自退回时间重新计算**（小时数同原券配置） | 不变 |
| 用券注单结算 · 赢 | — | 派彩＝**券面额 × 赔率（含本金）**，入会员余额 |
| 用券注单结算 · 赢半 【新增】 | — | 派彩＝**券面额 ÷ 2 × 赔率＋券面额 ÷ 2**，入会员余额 |
| 用券注单结算 · 输 | — | 无派彩 |
| 用券注单结算 · 输半 【新增】 | 不退回次数 | **退回一半现金**（券面额 ÷ 2），入会员余额 |

#### 输半／赢半（Half Lose／Half Win）说明 【新增】

> **什么是「输半」「赢半」**
> - 出现在亚洲盘的四分之一盘口（如让球 `0/0.5`、大小 `2/2.5`）：投注额一半算在较小盘、一半算在较大盘，赛果落在两者之间时：**输半**＝一半投注额判输、另一半退回；**赢半**＝一半投注额判赢、另一半退回。
> - 后台备注显示 `Settle:half lose`／`Settle:half win`。
> - 一般注单范例：₱200 输半 → 输 ₱100、退回 ₱100，输赢金额 `-100.00`；₱200 @1.90 赢半 → 赢 ₱90、退回 ₱100，输赢金额 `90.00`。

> **用券注单遇到「输半」**
> - 券已使用，**不退回次数**（与注单取消／作废会恢复为未使用不同）。
> - **退回一半现金**（券面额 ÷ 2）入会员余额。范例：₱100 券输半 → 退回 ₱50。
> - 输赢正常显示：前台 `Win/Lose`、后台「输赢金额」为 `-50.00`。

> **用券注单遇到「赢半」**
> - 派彩＝**券面额 ÷ 2 × 赔率＋券面额 ÷ 2**：赢的一半按赔率派彩，另一半本金也一并退回。
> - 范例：₱100 券 @1.90 赢半 → `50 × 1.90 ＋ 50 ＝ 145` 入余额。
> - 输赢正常显示：前台 `Win/Lose`、后台「输赢金额」为 `45.00`（145 − 100）。

#### 用券注单派彩与输赢（结算结果一览） 【新增】

| 结算结果 | 入会员余额 | 输赢（正常显示） | 范例（₱100 券） |
|---|---|---|---|
| 赢 | 券面额 × 赔率 | 派彩 − 券面额 | @7.40：入余额 `740`，输赢 `640.00` |
| 赢半 | 券面额 ÷ 2 × 赔率 ＋ 券面额 ÷ 2 | 派彩 − 券面额 | @1.90：入余额 `145`，输赢 `45.00` |
| 输 | `0` | −券面额 | 入余额 `0`，输赢 `-100.00` |
| 输半 | 券面额 ÷ 2（退回一半现金） | −券面额 ÷ 2 | 入余额 `50`，输赢 `-50.00` |
| 注单取消／作废 | `0`（原券恢复为未使用） | `0` | 入余额 `0`，输赢 `0.00` |

> 前台 `Win/Lose`、注单页 `Total Win/Loss`、后台体育注单「输赢金额」、各报表的输赢栏位，皆以此表的「输赢」为准（与一般注单的算法相同）。

#### 投注统计口径 【新增】

| 项目 | 用券注单 |
|---|---|
| Total Bet Amount（总投注金额） | 计入，以券面额计 |
| Total Valid Bet（有效投注） | **不计入** |
| 打码量 | **不计入** |
| Win/Lose（注单页单张卡片） | 计入，正常显示（见上方「结算结果一览」） |

#### 优惠券系统开关 【异动】

> 后台「优惠券管理 › 优惠券配置」的**「优惠券系统开关」关闭**时：
> - 前台所有玩法投注页的 **SportsVoucher 栏位同步隐藏**，只能一般金额投注。
> - 会员已领取的券暂时无法使用，有效期照常计算。
> - 开关重新开启后恢复显示。

#### 共通规则

1. 适用玩法：**单关（早盘／滚球）、单关预约**。
2. 不适用玩法：**OUTRIGHTS、ENDING CARD、ENDING GAME、串关**，不可使用体育投注券。
3. 一次下注只能使用**一张券**；**一张券只能使用 1 次**。
4. 用券下注**不检查余额**，余额为 0 也可下注。
5. 券面额需在该盘口**投注限额内**才可选；限额外的券反灰不可选（不显示提示文字），并**排序在清单下方**。
6. 编辑券配置**不影响已发出的券**；之后发出的是新券，与旧券无关。删除券配置后已发出的券仍可使用到期。

#### 交互

1. 清单区固定约 **3 张卡**高度，超过可上下滑动；选券或画面更新时保留滑动位置。
2. 点可用的券 → **选中**；同时只能选 1 张；再点同一张取消选择。
3. 用券下注成功后，该券**即从清单移除**（一张券只能使用 1 次）；该注单若被取消／作废，券**重新出现在清单**，依新的到期时间倒数。**过期的券在体育投注页移除不显示**。
4. **限额外的券：**依用券规范，单次投注金额不在本盘口限额内的券**反灰、不可点选**，**不显示**限额提示文字，并排在清单最后（见下方「排序」「限额判断」）。

#### 排序 【异动】

> 可选的券在上，依**到期时间由近到远**；**不能使用的券（限额外）排在最后**，同样依到期时间由近到远。

#### 限额判断

| 单次投注金额 vs 本盘口限额 | 卡片 | 位置 | 计入 n |
|---|---|---|---|
| 最小 ≤ 金额 ≤ 最大 | 可选 | 上方 | 是 |
| 金额 < 最小限额 | 反灰、不可点 | 最后 | 否 |
| 金额 > 最大限额 | 反灰、不可点 | 最后 | 否 |

> 投注页开着时若限额改变、已选的券变成限额外 → **自动取消选择**。

#### 缺省页 【新增】

1. **条件：**会员**没有任何体育投注券**（未过期且未使用的券为 0 张），开启 SportsVoucher 开关后，券清单区显示缺省页。
2. **内容：**缺省图示＋文案 `There does not have any content.`，沿用「我的优惠券」空页的图示样式；区块高度同券清单。
3. 只有限额外的券时**不显示缺省页**，照常显示反灰的券。
4. 显示缺省页时 `To Win` 为 `0.00`、`Place Bet` 反灰不可点；关闭开关即恢复一般金额投注。

#### Place Bet 检查（开关开启时）

1. 开启 SportsVoucher 但**未选券**：`Place Bet` **反灰不可点**；选券后恢复可点，取消选择又变回反灰。
2. 开启预约且预约赔率 ＜ 当前赔率 → 预约栏红框＋错误文案，`Place Bet` **反灰不可点**（见前台规则 4）。

4. 券面额已由前台规则 2 保证在限额内，送出时**不再做限额判断**；**不检查余额**。

   - `Details` → 注单页 Scheduled。
5. **使用时点：**送出预约时券**仍为未使用**；**预约赔率匹配成功（成交）当下才变为已使用**。
6. **不锁定券：**
   - 预约期间该券仍显示在券清单，仍可用于其他投注。
   - **成交当下若该券已过期或已使用，此预约单状态变更为失败**（注单页 Expired · `Booking failed`）。

### 前台规则 5 · 封盘 / 无可用券 【新增】

## 判断逻辑

*下注判断 · 预约用券 · 券可用判断 · 券清单排序*

#### 用券下注判断流程

```
开启 SportsVoucher
  └ 未选券 → Place Bet 反灰不可点
  └ 选券后，会员择一操作：
     操作 A · 一般投注
       1. 直接点击 Place Bet
       2. 处理中 `The order is being processed......`
       3. 成功 → 券变为已使用、从清单移除
          失败 / 赔率已变 → 券仍为未使用（可 Accept and bet 重送）
     操作 B · 预约投注
       1. 点击 + Booking，设定预约赔率
       2. 预约赔率 < 当前赔率 → 预约栏红框＋红字，Place Bet 反灰不可点
          （调整为预约赔率 ≥ 当前赔率后才可点）
       3. 点击 Place Bet → 预约成功（券仍为未使用、不锁定）→ Scheduled
       4. 预约赔率匹配成功当下：
          券未过期且未使用 → 券变为已使用、成交 → Unsettled
          券已过期或已使用 → 预约单失败 → Expired · Booking failed
```

#### 券是否出现在清单 / 可否选取

| 优惠券系统开关 | 玩法 | 券已过期 | 券已使用 | 面额在限额内 | 呈现 |
|---|---|---|---|---|---|
| 关闭 | 任意 | — | — | — | 体育投注页 SportsVoucher 栏位隐藏 |
| 开启 | OUTRIGHTS | — | — | — | 栏位反灰不可点 |
| 开启 | ENDING CARD／ENDING GAME／串关 | — | — | — | 无此栏位 |
| 开启 | 单关 | 是 | — | — | 体育投注页不显示 |
| 开启 | 单关 | 否 | 是 | — | 不显示（已使用） |
| 开启 | 单关 | 否 | 否 | 否 | 显示、反灰不可选，排最后 |
| 开启 | 单关 | 否 | 否 | 是 | 显示、可选，计入 n available |

#### 边界与异常

| 情境 | 处理 |
|---|---|
| 已成交的用券注单被取消／作废 | 注单显示 `Bet Cancellation`；**原券恢复为未使用**，有效期自退回时间重新计算；后台同一笔记录状态改回未使用，备注 `注单 {订单号} 取消，已退回` |
| 券在投注页开着时到期 | 倒数至 `00:00:00` 即自动从清单移除（已选则取消选择），`n available` 同步减少 |
| 用券注单结算 · 赢 | 派彩＝券面额 × 赔率入余额；输赢正常显示（派彩 − 券面额） |
| 用券注单结算 · 赢半 | 派彩＝券面额 ÷ 2 × 赔率＋券面额 ÷ 2 入余额（例 ₱100 @1.90 → 145）；输赢 `45.00` |
| 用券注单结算 · 输 | 无派彩；输赢 `-券面额` |
| 用券注单结算 · 输半 | 退回一半现金（券面额 ÷ 2）入余额，不退回次数；输赢 `-券面额 ÷ 2` |
| 余额为 0 | 仍可用券下注 |
| 后台球类报表 · 用券注单 | 投注区：投注次数、投注人数、投注金额、免费投注皆计入；已结算区：有效投注数／人数／金额、会员输赢（不含退水、免费投注）、会员盈利率不计入，今日结算注单、今日结算注单总投注额、输赢金额、免费投注数、免费投注输赢计入 |
| 后台体育注单 · 用券注单 | 备注另起一行 `SportsVoucher`；画面输入金额／下注金额＝券面额；有效下注金额 `0.00`；输赢金额正常计算 |
| 平台报表／会员报表 · 用券注单 | 见后台规则 7、9 |
| 编辑券配置 | 已发出的券不变；之后发出的是新券 |
| 删除券配置 | 不可再赠送；已发出的券可用到期 |
| 优惠券系统开关关闭→开启 | 体育投注页 SportsVoucher 栏位隐藏 → 恢复显示；期间券有效期照常计算 |
