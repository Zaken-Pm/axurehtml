### 1. 赛事筛选栏（状态／日期 + 单串）

> 🖼️ 图：原型截图 — 赛事列表 IN-PLAY

| 项目 | 说明 |
| --- | --- |
| 用途 | 赛事列表最上面那排「筛选钮」——让玩家挑要看哪一天、哪种状态的比赛：正在打的（滚球）、今天的、之后几天的；右侧还能切「单式／串关」两种下注方式。 |
| 顺序 | IN-PLAY、TODAY、之后 3 天日期（大写缩写如 `SEP-18`）、日期图标 📅、OUTRIGHT、ENDING CARD、ENDING GAME；右侧固定 SINGLE／P。可水平滑动。 |
| 预设 | 进入列表预设选中 **IN-PLAY**。 |
| 条件显示 | ENDING CARD／ENDING GAME 仅在选择**篮球**时显示。 |
| 球种过滤 （变更） | 列表依所选**球种 Tab** 仅显示该球种的联赛与赛事；**对应球种无实际赛事时补一场示意赛事**，确保每个球种皆可进入详情检视对应计分板。 |
| 单串切换 | SINGLE（单式）／P（串关）；选 PARLAY 时仅显示可串关赛事。 |

**分页 × 显示赛事 情境穷举**

| 选中分页 | 显示赛事 | 备注 |
| --- | --- | --- |
| IN-PLAY | 仅「已开赛（滚球）」赛事 | 其余日期不含滚球 |
| TODAY | 当日「未开赛」赛事 | 不含滚球 |
| 后 3 天日期 | 该日期未开赛赛事 | 无赛事→缺省页 |
| 日期图标后 3 日 | 该日期未开赛赛事 | 选中后图标高亮 |
| OUTRIGHT / ENDING CARD / GAME | 跳转对应页 | — |

### 3. 赛事卡（一屏三玩法）

> 🖼️ 图：原型截图 — 赛事卡

| 项目 | 说明 |
| --- | --- |
| 用途 | 列表里每一场比赛的「一张卡」——一行即可看到时间／比分、两支队伍、以及三种下注玩法的赔率；点赔率数字即可下注。 |
| 交互 | 每场一列：时间／状态（滚球显示节次＋时间＋红点动画）、MORE（进详情）、三玩法栏、队伍列、赔率格、小节比分（滚球）。点赔率格展开投注单。 |
| 发球权 | 网球／羽球／乒乓球在队徽左侧以**绿色直条**标示发球方。 |
| 让分强队 | 让分为负（较强队）之队名以**红字**提示（全球种）。 |
| 比分 | 固定位置、单行呈现，不随文案变动位置。 |
| 文案长度 | 队名**最多显示两行**，超过以省略号「…」呈现；有／无发球直条的列须左对齐一致。 |
| 一屏三玩法 | 右侧玩法区**一屏正好显示三组赔率**（足球即「让球／进球 大小／1X2 含和局」），栏位等分**填满视区**、不露出第四组；**第四组玩法起以左右滑动**查看。 |
| 红黄牌（足球） | 滚球足球以小色块显示红／黄牌（**黄底**／**红底**＋张数），各队分别显示且**靠右贴齐总分（各队红黄牌右缘对齐、总分置最右）**；**张数 > 0 才显示**，为 0 则不出现（中立场 N、角球 ⛳ 维持原位）。 |
| 赔率升降 | 数字变色（升绿／降红）＋箭头动画，约 **2～2.5 秒**后颜色复原；收合再展开后样式须正常、不残留。 |

| 情境 | 条件 | 呈现／行为 |

### 5. 缺省页（无内容）

> 🖼️ 图：原型截图 — 缺省页

| 项目 | 说明 |
| --- | --- |
| 用途 | 当所选日期／筛选「完全没有比赛」时，改显示一张空状态插画与提示文案，而非一片空白，让玩家知道不是当机、只是没赛事。 |

**未开赛状态穷举（通用）· 即将 / 今日 / 早盘**

> 💡 ◈ 不同运动「比赛进行到哪」的表示方式不一样（足球用上下半场、篮球用第几节、网球用第几盘…）；下面两张表分别列出各球种「滚球中」与「未开赛」时画面显示的内容。 共同规则：滚球赛事顶部左侧显示 赛事进程 （含即时倒数／节·盘·局），每队于队名右侧显示 即时比分 ；需逐盘／逐局历史的球种（网球、排球、羽球、乒乓）于卡片底部显示 各盘／局比分 。队伍名称最多 两行 ，超出以「…」省略。未开赛（即将／今日／早盘）不显示即时比分，仅显示开赛时间与赛制，并锁定尚未开放之盘口。

## 赛事详情

_对应原型：计分板 / 更多赛事 / 置顶比分栏 / 市场玩法_

### 1. 计分板（多状态）

> 🖼️ 图：有直播/动画 — 计分板 视频

| 项目 | 说明 |
| --- | --- |
| 用途 | 点进一场比赛后最上方的「即时比分板」——像看转播时萤幕上方的比分条，显示目前几比几、打到第几节／盘、有无直播画面。 |
| 返回箭头 | 左上返回 ‹ 置于滚动区内，随页面上滑一起卷动（**不吸顶**）；无视频计分板不重复显示返回箭头。 |
| 计分板下方 | Favorite（收藏）、Video、Animation 切换（Video／Animation 仅「有直播」赛事显示）。 |
| 情境驱动 （变更） | 计分板**不再**以示意切换钮手动切换；**球种**取自球类 Tab／所点赛事，**状态**取自赛事本身（有直播／滚球／未开赛），进入详情时自动呈现对应计分板。 |

**计分板状态穷举（判断逻辑表）**

| 状态 | 呈现 | 联赛名下拉（更多赛事） |
| --- | --- | --- |
| 有直播／动画 | 影片区 + 精简比分条（LIVE、比分、节次、⚙ ⛶） | **不**显示 |
| 无直播·滚球 | 纯比分计分板（队徽、比分、节次表） | 顶部中央「联赛名 ▾」**可点击** |
| 无直播·未开赛 | 纯赛前板（队伍、开赛时间、倒数） | 顶部中央「联赛名 ▾」**可点击** |
| 优胜冠军 | 冠军示意板（无实时比分） | 不显示 |

> 🖼️ 图：无直播·滚球 — 计分板 无视频

> 💡 ▾ 无直播（纯比分）状态：顶部中央显示「 联赛名 ▾ 」，点击展开该联赛「更多赛事」清单（见下）。

### 2. 更多赛事（切换比赛）

### 3. 置顶精简比分栏

> 🖼️ 图：滑动后置顶 — 置顶比分栏

| 项目 | 说明 |

| 交互 | 详情页上滑逾约 40px 后，顶部滑入白底精简比分栏：左返回 ‹、主队队徽+队名、中央橙色比分「93 - 115」+ 下方节次「4th Qtr」、右客队队名+队徽。滑回顶部即收起。 |

### 4. 市场玩法 · Winner

> 🖼️ 图：原型截图 — Winner

| 项目 | 说明 |
| --- | --- |
| 用途 | 「玩法」＝一种下注题目。Winner（独赢）是最单纯的一种：直接猜「哪一队会赢」。 |
| 市场 Tab | All Markets／Player／Picks 切换；此 Tab **不吸顶**，随页面卷动。玩法可点标题收合／展开，可点星形置顶（Pin）。 |
| 版面 | 两栏（主／客）。角落 HOME（主队卡右上）／AWAY（客队卡左上，朝中间）小灰标。 |
| 队伍 | 队徽 **64px** 置外侧（主左客右）；队名主队**靠右**、客队**靠左**（皆朝中间），距卡片内缘约 4～6px，过长换行。 |
| 赔率 | 数字于赔率框内**置中**；升降箭头在外侧（主队右、客队左）。点击展开投注单并高亮所选。 |

### 5. 市场玩法 · Handicap

> 🖼️ 图：原型截图 — Handicap

| 项目 | 说明 |
| --- | --- |
| 用途 | Handicap（让分盘）是为了让强弱两队下注更公平：先帮强队「扣掉」几分（或几球）再比（例：强队 -4.5，要赢超过 5 分，押它才算赢）。 |
| 版面 | 与 Winner 同（HOME/AWAY 标、队徽外侧、队名朝中）。 |
| 赔率行 | 每行「让分值（左）＋赔率（右）＋升降箭头（外侧）」，共三档；选中档深蓝底黄字。 |

### 6. 市场玩法 · Total Points

> 🖼️ 图：原型截图 — Total Points

| 项目 | 说明 |
| --- | --- |
| 用途 | Total Points（大小盘）不猜谁赢，而是猜两队「加起来的总分」会超过（大 Over）还是低于（小 Under）一个设定值（例：设 150.5，猜两队总分是否破 150.5）。 |
| 版面 | 两栏，球头以 `O 93.5`／`U 94.5` 显示（不显示主客队徽队名）。标题无「?」图标。 |

> 💡 ◈ 足球 1X2（Home／Draw／Away 三栏、Draw 无队徽）为球种差异玩法示意，版面参照 Winner（队徽＋队名＋置中赔率框）。

**名词小辞典（白话解释）**

> 💡 ✔ 看规格时遇到不懂的词，先来这里查——以下用最白话的方式解释体育彩票常见名词。

| 名词 | 白话解释 |
| --- | --- |
| 滚球 / In-Play | 正在进行中的比赛，可以边看边下注（赔率会随比况一直变动）。 |
| 早盘 / 今日 / 即将 | 都是「还没开打」的比赛。早盘＝比较后面几天；今日＝今天稍晚开打；即将＝马上要开打、正在倒数。 |
| 独赢 / Winner | 最单纯的玩法，猜「哪一队会赢」。 |
| 1X2 | 足球专用的独赢。因为足球会「和局」，所以有三个结果：1＝主队胜、X＝和局、2＝客队胜。 |
| 让分盘 / 让球 / Handicap | 两队实力差很多时，先帮强队「扣掉」几分或几球再比，让两边下注更公平。让分是负数的那一队＝被看好的强队（原型用红字标示）。 |
| 大小盘 / Total / 大 小(O/U) | 不猜谁赢，改猜两队「加起来的总分／总进球」会「超过（大 Over）」还是「低于（小 Under）」一个设定的数字。 |
| 盘口 / 赔率 | 一个可下注的选项＋它的赔率数字（数字越大＝越冷门、赢了赔越多）。显示🔒锁头＝此选项暂时不开放下注。 |
| 单式 / Single | 一次只下一注，一场比赛独立结算。 |
| 串关 / Parlay / P | 把好几场比赛绑成「一注」，要「全部猜中」才赢；赔率叠加、奖金更高，但更难中。 |
| 计分板 / Scoreboard | 点进一场比赛后最上方那块，显示即时比分、打到第几节／盘、有没有直播画面。 |
| 赛事进程 | 表示「比赛进行到哪」。各运动讲法不同：足球＝上／下半场＋时间、篮球＝第几节、网球＝第几盘、棒球＝第几局等。 |
| 即时比分 / 小比分 | 目前的比分。部分运动会在卡片下方再列出「每一节／每一盘」的分数（小比分）。 |
| 冠军 / 优胜 / Outright | 不押单场输赢，而是押整个赛季或整个赛事「最后谁夺冠」。 |
| Ending Card / Ending Game | 篮球才有的特殊玩法分类，押某个时段结束时的比分／结果（本次不列规格）。 |
| 置顶 / Pin | 把常用的玩法「钉」在最上面，方便快速找到。 |
| 发球权 | 网球、羽球、乒乓等运动，目前轮到哪一方发球（原型用队徽旁的绿色直条标示）。 |
| 赛制 / Best of 5 / 5 局 3 胜 | 要先赢几盘（或几局）才算赢整场。例：5 局 3 胜＝先赢 3 局者胜。 |
| 补时 | 足球上、下半场快结束时，裁判追加的补偿时间。 |
| 缺省页 / 空状态 | 筛选后「没有任何比赛」时显示的提示画面，避免整片空白让人误以为当机。 |
