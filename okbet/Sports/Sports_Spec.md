## 体育 Sports 需求规格

_本文件整并**前台**（首页／赛事列表／赛事详情）与**后台**（联赛管理·普通联赛集群）之规格与可点选原型。后台之设定会影响前台呈现（如「新赛季」），相关连动已于对应页签标注。原型可于「原型预览」切换前台／后台检视。_

版本 **v1.0** · 日期 **2026-09-24**

**需求目的**

> 💡 ◈ 提供体育（Sportsbook）手机前台的完整浏览与投注示意流程，让玩家依「**球种 → 赛事状态／日期 → 联赛 → 赛事 → 玩法 → 投注**」路径完成选注。本规格描述前台各区块的呈现、交互与各种情境（含成功、失败、空值、开关切换）。

> 💡 ✔ 标记说明： 本次新增、 修改既有、未标示者沿用既有。

### 5. 足球 1X2 三按钮玩法（示意）

> 🖼️ 图：原型截图 — 足球 1X2

| 项目 | 说明 |
| --- | --- |
| 用途 | 足球会出现「和局」，赔率按钮为三颗（主队赢／和局／客队赢）；其他球类通常两颗（主队赢／客队赢）。 |
| 交互 | 足球赔率按钮为 **Home／Draw／Away** 三格；球头（标签）与赔率**左右并排**，整组置中，升降箭头紧贴赔率数字右侧。 |
| Winner 标签 | Winner 两颗赔率按钮**不显示「主／客」（Home／Away）文案**，仅置中显示赔率数字（含升降箭头）；中间维持「Winner」标示。足球 1X2 三格仍显示 Home／Draw／Away。 |
| 队名区高度 | 队名区**固定为两行高度**：不足两行时保留第二行空间、超过两行以省略号「…」截断，使卡片高度不随队名长短变动。 |
| 赔率列对齐 | 因队名区高度固定，**同一排各卡片的赔率按钮列位于同一水平线**；队伍栏宽度足以容纳较长队名（如「Golden State」）单行不折行。 |
| 球头／赔率排列 | **1X2、Handicap** 的赔率格采「**球头（盘口值／标签）在左、赔率在右**」左右并排显示；**Winner** 维持原样（仅置中显示赔率、无球头文案，不更动）。 |

## 赛事列表

_对应原型：赛事筛选栏 / 赛事列表 / 联赛筛选 / 缺省页_

### 1. 赛事筛选栏（状态／日期 + 单串）

> 🖼️ 图：原型截图 — 赛事列表 IN-PLAY

| 项目 | 说明 |
| --- | --- |
| 用途 | 赛事列表最上面那排「筛选钮」——让玩家挑要看哪一天、哪种状态的比赛：正在打的（滚球）、今天的、之后几天的；右侧还能切「单式／串关」两种下注方式。 |
| 球种过滤 | **操作流程：先选球种（球类 Tab）→ 再选赛事状态「已开赛／未开赛」。**列表依所选**球种 Tab** 仅显示该球种的联赛与赛事。 |
| 赛事筛选 | IN-PLAY、TODAY、之后 3 天日期（大写缩写如 `SEP-18`）、日期图标 📅、OUTRIGHT、ENDING CARD、ENDING GAME；右侧固定 SINGLE／P。可水平滑动。 |
| 预设 | 进入列表预设选中 **IN-PLAY**。 |
| 条件显示 | ENDING CARD／ENDING GAME 仅在选择**篮球**时显示。 |
| 单串切换 | **预设 Single（单式）**；选 **Parlay（串关）**时，滚球与早盘**仅显示可串关的赛事**。本期仅做赛事筛选，购物车不会同步更动。 |
| Parlay 锁定 | 处于 Parlay 时点击「**Outright／Ending Card／Ending Game**」，筛选**自动切回 Single**；且在此三个玩法页面**锁定 Single、不可切换为 Parlay**（切换钮置灰不可点）。离开这三页回到一般列表即解除锁定。 |

**分页 × 显示赛事 情境穷举**

| 选中分页 | 显示赛事 | 备注 |
| --- | --- | --- |
| IN-PLAY | 仅「已开赛（滚球）」赛事 | 其余日期不含滚球 |
| TODAY | 当日「未开赛」赛事 | 不含滚球 |
| 后 3 天日期 | 该日期未开赛赛事 | 无赛事→缺省页 |
| 日期图标后 3 日 | 该日期未开赛赛事 | 选中后图标高亮 |
| OUTRIGHT / ENDING CARD / GAME | 跳转对应页 | — |

### 3. 赛事卡（一屏三玩法）

> 🖼️ 图：原型截图 — 赛事卡

| 项目 | 说明 |
| --- | --- |
| 用途 | 列表里每一场比赛的「一张卡」——一行即可看到时间／比分、两支队伍、以及三种下注玩法的赔率；点赔率数字即可下注。 |
| 交互 | 每场一列：时间／状态（滚球显示节次＋时间＋**脉冲图标**，进程文案**灰色**）、更多盘口数（进详情）、三玩法栏、队伍列、赔率格。点赔率格展开投注单。滚球赛事**不再显示底部分节小比分**（各节／盘／局比分），仅保留每队即时总分。 |
| 总分颜色 | 各队即时**总分统一以橘色显示**（全球种一致）。 |
| 网球总分 | 网球滚球卡**仅显示总分（盘数）**，不再显示「盘·局·分」三段式；总分位置与其他球类一致（队名右侧、橘色）。 |
| 发球权 | 网球／羽球／乒乓球在队徽左侧以**绿色直条**标示发球方。 |
| 让分强队 | 让分为负（较强队）之队名以**红字**提示（全球种）。 |
| 比分 | 固定位置、单行呈现，不随文案变动位置。 |
| 文案长度 | 队名**最多显示两行**，超过以省略号「…」呈现；有／无发球直条的列须左对齐一致。 |
| 一屏三玩法 | 右侧玩法区**一屏正好显示三组赔率**；**所有球种前三个玩法统一，由左至右为「1X2（或 Winner）／让球／大小」**，栏位等分**填满视区**、不露出第四组；第四组玩法起以左右滑动查看。 |
| 足球卡精简 | 滚球足球卡**移除**红黄牌、角球（⛳）、中立场（N）；队伍列保留**队徽＋队名＋该队即时总分**（如 2／1），**不显示底部小比分**。 |
| 赔率升降 | 数字变色（升绿／降红）＋箭头动画，约 **2～2.5 秒**后颜色复原；收合再展开后样式须正常、不残留。 |
| 底部图标列 | 赛事卡**移除原底部图标列**（预约投注／兑现／动画／视频／收藏），不再显示该栏位。 |

## 赛事详情

_对应原型：计分板 / 更多赛事 / 置顶比分栏 / 市场玩法_

### 1. 计分板（多状态）

> 🖼️ 图：有直播/动画 — 计分板 视频

| 项目 | 说明 |

**名词小辞典（白话解释）**

> 💡 ✔ 看规格时遇到不懂的词，先来这里查——以下用最白话的方式解释体育彩票常见名词。

| 名词 | 白话解释 |
| --- | --- |
| 滚球 / In-Play | 正在进行中的比赛，可以边看边下注（赔率会随比况一直变动）。 |
| 早盘 / 今日 / 即将 | 都是「还没开打」的比赛。早盘＝比较后面几天；今日＝今天稍晚开打；即将＝马上要开打、正在倒数。 |
| 独赢 / Winner | 最单纯的玩法，猜「哪一队会赢」。 |
| 1X2 | 足球专用的独赢。因为足球会「和局」，所以有三个结果：1＝主队胜、X＝和局、2＝客队胜。 |
| 让分盘 / 让球 / Handicap | 两队实力差很多时，先帮强队「扣掉」几分或几球再比，让两边下注更公平。让分是负数的那一队＝被看好的强队（原型用红字标示）。 |
| 大小盘 / Total / 大 小(O/U) | 不猜谁赢，改猜两队「加起来的总分／总进球」会「超过（大 Over）」还是「低于（小 Under）」一个设定的数字。 |
| 盘口 / 赔率 | 一个可下注的选项＋它的赔率数字（数字越大＝越冷门、赢了赔越多）。显示🔒锁头＝此选项暂时不开放下注。 |
| 单式 / Single | 一次只下一注，一场比赛独立结算。 |
| 串关 / Parlay / P | 把好几场比赛绑成「一注」，要「全部猜中」才赢；赔率叠加、奖金更高，但更难中。 |
| 计分板 / Scoreboard | 点进一场比赛后最上方那块，显示即时比分、打到第几节／盘、有没有直播画面。 |
| 赛事进程 | 表示「比赛进行到哪」。各运动讲法不同：足球＝上／下半场＋时间、篮球＝第几节、网球＝第几盘、棒球＝第几局等。 |
| 即时比分 / 总分 | 目前的比分（每队即时总分）。**卡片下方的分节小比分（每一节／盘／局分数）已移除，不再显示。** |
| 冠军 / 优胜 / Outright | 不押单场输赢，而是押整个赛季或整个赛事「最后谁夺冠」。 |
| Ending Card / Ending Game | 篮球才有的特殊玩法分类，押某个时段结束时的比分／结果（本次不列规格）。 |
| 置顶 / Pin | 把常用的玩法「钉」在最上面，方便快速找到。 |
| 发球权 | 网球、羽球、乒乓等运动，目前轮到哪一方发球（原型用队徽旁的绿色直条标示）。 |
| 赛制 / Best of 5 / 5 局 3 胜 | 要先赢几盘（或几局）才算赢整场。例：5 局 3 胜＝先赢 3 局者胜。 |
| 补时 | 足球上、下半场快结束时，裁判追加的补偿时间。 |
