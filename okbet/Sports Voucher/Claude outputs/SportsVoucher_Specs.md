# Sports Voucher · 体育投注券

营运可发放「固定金额、限定次数、限时有效」的体育投注券给会员；会员在体育单关投注时直接用券下注、不动用自己的余额。用于赛事营销（如世界杯开幕赠券）、拉新与回流，并可在后台追踪每张券的状态与剩余次数。

- 版本：v1
- 后台位置：积分商城 › 优惠券管理／发券审核
- 前台位置：体育 › Bet Slip／My Bets Slip
- 关联原型：前台 · 后台

> 本文件由 HTML 规格（SportsVoucher_Specs.html）转出，供 AI／开发阅读。截图档名对应规格内 `img/` 资料夹；前台原型 `SportsVoucherFront.html`、后台原型 `SportsVoucher_Backend.html`。

## 通用规则

*名词定义 · 券的生命周期 · 扣次与退回 · 派彩与统计口径 · 系统开关*

#### 名词定义

| 项目 | 说明 |
|---|---|
| 体育投注券 | 后台称「体育投注券」，前台显示 `SportsVoucher`。属于「优惠券」的一个类别（与存送比例券、输返券、中奖加奖券并列）。 |
| 单次投注金额 | 券面额。每次用券下注的**固定金额**，会员不可修改；**整数**，币种依券的币种。 |
| 投注次数 | 一张券可下注的总次数；**每成功下注一次扣 1**，剩余 0 次即用完。 |
| 有效期 | 单位**小时**。自券**发放到会员账户**起算；到期未用完的次数作废。到期时间＝发放时间＋有效期，精确到分钟。 |
| 投注限额 | 该盘口的最小／最大投注金额，沿用现有限额来源；前台显示 `Limit {最小限额}-{最大限额}`，数值依各盘口实际限额带入（如 `Limit 1-9,999`、`Limit 200-800`）。 |
| 预约投注 | 前台按钮 `Booking`。设定预约赔率，盘口赔率匹配成功时才成交。 |

#### 券的生命周期 【新增】

流程：[发券审核通过 或 注单退回] →（入账） [未使用] →（下注成功 −1） [已使用 剩余 ≥ 1，可继续用] →（剩余 = 0） [已使用（用完）]

> **到期**
> - 「未使用」或「已使用但仍有剩余」的券，到期即变为**已过期**，剩余次数作废。
> - **体育投注页移除不显示**；My voucher 移至 `Expired`。
>
> **已用完（剩余 0）**
> - 体育投注页同样**移除不显示**（最后一次下注成功后即从清单消失）。
> - My voucher 移至 `Used`。
> - 后台状态维持「已使用」，到期后也不改为「已过期」。

> 每张券在后台「优惠券记录」是**一笔记录**，状态只有三种：**未使用／已使用／已过期**（「待结算」不适用于体育投注券）。「已使用」＝至少成功用过 1 次，剩余次数写在备注。

#### 扣次、退回与派彩 【新增】

| 情境 | 券次数 | 会员余额 |
|---|---|---|
| 用券下注，投注成功 | **扣 1 次** | 不检查、不扣除 |
| 投注失败（`Betting failed`） | 不扣 | 不变 |
| 赔率已变更导致失败 → 按 `Accept and bet` 重送成功 | 重送成功时扣 1 次 | 不变 |
| 预约投注：送出预约 | 不扣 | 不变 |
| 预约投注：预约赔率匹配成功（成交） | **成交当下扣 1 次** | 不变 |
| 预约投注：成交当下券已过期或剩余 0 次 | 不扣；**此预约单状态变更为失败**（注单页 Expired · `Booking failed`） | 不变 |
| 预约投注：未成交、取消 | 不扣 | 不变 |
| 已成交的用券注单被取消／作废（Void、赛事取消等） | **退回一张新券**：1 次、单次投注金额同原券、**有效期自退回时间重新起算**（小时数同原券配置）；原券不恢复 | 不变 |
| 用券注单结算 · 赢 | — | 派彩＝**券面额 × 赔率（含本金）**，入会员余额 |
| 用券注单结算 · 输 | — | 无派彩 |
| 用券注单结算 · 赢半 【新增】 | 已扣的 1 次不退回 | 派彩＝**券面额 ÷ 2 × 赔率＋券面额 ÷ 2**（含另一半本金），入会员余额 |
| 用券注单结算 · 输半 【新增】 | 已扣的 1 次**不退回**，**不补券** | 无派彩，**不退回金额** |

> **派彩范例：**
> - ₱100 券、赔率 `7.40`，赢 → 派彩 `100 × 7.40 = 740` 入余额。
> - 投注页与注单页的 `To Win` 皆以「券面额 × 赔率」显示。

#### 输半／赢半（Half Lose／Half Win）说明 【新增】

> **什么是「输半」「赢半」**
> - 出现在亚洲盘的四分之一盘口（如让球 `0/0.5`、大小 `2/2.5`）：投注额一半算在较小盘、一半算在较大盘，赛果落在两者之间时：**输半**＝一半投注额判输、另一半退回；**赢半**＝一半投注额判赢、另一半退回。
> - 后台备注显示 `Settle:half lose`／`Settle:half win`。
> - 一般注单范例：₱200 输半 → 输 ₱100、退回 ₱100，输赢金额 `-100.00`；₱200 @1.90 赢半 → 赢 ₱90、退回 ₱100，输赢金额 `90.00`。

> **用券注单遇到「输半」**
> - **仍消耗 1 次**（下注成功时已扣，不退回次数）。
> - **不退回任何金额**，也**不补券**（与注单取消／作废会退回新券不同）。
> - 前台 `Win/Lose`、后台「输赢金额」皆为 `0`，与「输」相同。

> **用券注单遇到「赢半」**
> - 已扣的 1 次不退回。
> - 派彩＝**券面额 ÷ 2 × 赔率＋券面额 ÷ 2**：赢的一半按赔率派彩，另一半本金也一并计入。
> - 范例：₱100 券 @1.90 赢半 → `50 × 1.90 ＋ 50 ＝ 145` 入余额。
> - 前台 `Win/Lose`、后台「输赢金额」皆显示派彩金额（例 `145.00`）。

#### 投注统计口径 【新增】

| 项目 | 用券注单 |
|---|---|
| Total Bet Amount（总投注金额） | **不计入** |
| Total Valid Bet（有效投注） | **不计入** |
| 打码量 | **不计入** |
| Win/Lose（注单页单张卡片） | 赢、赢半＝**派彩金额**；输、输半＝**0**（见前台规则 11） |
| 注单页汇总列 | 逐项见前台规则 10「汇总列」 |

#### 优惠券系统开关 【异动】

> 后台「优惠券管理 › 优惠券配置」的**「优惠券系统开关」关闭**时：
> - 前台所有玩法投注页的 **SportsVoucher 栏位同步隐藏**，只能一般金额投注。
> - 会员已领取的券暂时无法使用，有效期照常计算。
> - 开关重新开启后恢复显示。

#### 共通规则

1. 适用玩法：**单关（早盘／滚球）、单关预约**。
2. 不适用玩法：**OUTRIGHTS、ENDING CARD、ENDING GAME、串关**，不可使用体育投注券。
3. 一次下注只能使用**一张券**；一张券一次只扣 **1 次**。
4. 用券下注**不检查余额**，余额为 0 也可下注。
5. 券面额需在该盘口**投注限额内**才可选；限额外的券反灰不可选（不显示提示文字），并**排序在清单下方**。
6. 编辑券配置**不影响已发出的券**；之后发出的是新券，与旧券无关。删除券配置后已发出的券仍可使用到期。

#### 卡片内容（由左至右）

| 项目 | 说明 |
|---|---|
| 左侧图示 | 券图示；限额外的券反灰不可选（见下方「限额判断」）。 |
| 金额 | 单次投注金额，例 `₱100`、`₱20,000`：币种符号＋整数＋千分位、不显示小数；最多 9 位数，单行完整显示。 |
| 金额说明 | 固定文案 `Amount per bet`。 |
| 效期倒数 | 时钟图示＋剩余有效时间，依后台「有效期（小时）」自发券时起算倒数；**剩余 ≥ 24 小时：**显示「天数`d` `hh:mm`」，例 `9d 19:58`＝9 天 19 小时 58 分；刚好 1 天显示 `1d 00:00`；天数不补 0；**未满 24 小时：**显示 `hh:mm`，例 `23:59`、`00:44`；**每分钟更新**，秒数无条件舍去；倒数至 `00:00` 时该券**自动从清单移除**（已选则取消选择）。 |
| 右侧次数 | `x10`（剩余次数）。 |

#### 交互

1. 清单区固定约 **3 张卡**高度，超过可上下滑动；选券或画面更新时保留滑动位置。
2. 点可用的券 → **选中**；同时只能选 1 张；再点同一张取消选择。
3. 用券下注成功后，该券次数 −1；**减到 0 即从清单移除**。**过期的券在体育投注页移除不显示**。
4. **限额外的券：**依用券规范，单次投注金额不在本盘口限额内的券**反灰、不可点选**，**不显示**限额提示文字，并排在清单最后（见下方「排序」「限额判断」）。

#### 排序 【异动】

> 可选的券在上，依**到期时间由近到远**；**不能使用的券（限额外）排在最后**，同样依到期时间由近到远。

#### 限额判断

| 单次投注金额 vs 本盘口限额 | 卡片 | 位置 | 计入 n |
|---|---|---|---|
| 最小 ≤ 金额 ≤ 最大 | 可选 | 上方 | 是 |
| 金额 < 最小限额 | 反灰、不可点 | 最后 | 否 |
| 金额 > 最大限额 | 反灰、不可点 | 最后 | 否 |

> 投注页开着时若限额改变、已选的券变成限额外 → **自动取消选择**。

#### 缺省页 【新增】

1. **条件：**会员**没有任何体育投注券**（未过期且剩余次数 ≥ 1 的券为 0 张），开启 SportsVoucher 开关后，券清单区显示缺省页。
2. **内容：**缺省图示＋文案 `There does not have any content.`，沿用「我的优惠券」空页的图示样式；区块高度同券清单。
3. 只有限额外的券时**不显示缺省页**，照常显示反灰的券。
4. 显示缺省页时 `To Win` 为 `0.00`、`Place Bet` 反灰不可点；关闭开关即恢复一般金额投注。

#### To Win

| 情况 | To Win | 右侧 |
|---|---|---|
| 开关关闭 | 输入金额 × 赔率 | `Balance` |
| 开关开启、未选券 | `0.00`（Place Bet 反灰） | 不显示 |
| 开关开启、已选券 | 券面额 × 赔率 | 不显示（无 Balance、无限额） |
| 开启预约 | 以**预约赔率**计算 | 同上 |

#### Place Bet 检查（开关开启时）

1. 开启 SportsVoucher 但**未选券**：`Place Bet` **反灰不可点**；选券后恢复可点，取消选择又变回反灰。
2. 开启预约且预约赔率 ＜ 当前赔率 → 预约栏红框＋错误文案，`Place Bet` **反灰不可点**（见前台规则 4）。
3. 盘口已关闭 → `Place Bet` 反灰（见前台规则 5）。
4. 券面额已由前台规则 2 保证在限额内，送出时**不再做限额判断**；**不检查余额**。

### 前台规则 4 · 预约投注 Booking × SportsVoucher 【新增】

截图：
- 前台截图 · 用券＋预约（`img/f05_sv_reserve.png`）
- 前台截图 · 预约赔率过低（`img/f06_reserve_err.png`）
- 前台截图 · 预约成功（`img/f13_reserve_ok.png`）

1. **按钮：**`+ Booking` 位于原 Parlay 按钮位置（Place Bet 左侧）；点击开启预约，按钮变 `Cancel`；再点关闭。
2. **预约赔率栏** `− @1.92 +`：预设＝当前赔率＋0.10；每次 ±0.01；最低 1.01。开关关闭时在金额栏下方；**开关开启时在券清单上方**。
3. **预约赔率 ＜ 当前赔率：**
   - 预约栏红框，下方红字 `The reservation odds cannot be lower than handicap odds`。
   - 显示红字期间 `Place Bet` **反灰不可点**。
   - 调回 ≥ 当前赔率后红框与红字消失，`Place Bet` 恢复可点。
4. **成功：**
   - 提示 `Your Reservation Was Placed Successfully`＋`Reservation Odds`。
   - 右上显示 `SportsVoucher: 金额`。
   - `Details` → 注单页 Scheduled。
5. **扣次：**送出预约**不扣**；**预约赔率匹配成功（成交）当下才扣 1 次**。
6. **不锁定次数：**
   - 预约期间券清单仍显示原次数，该券仍可用于其他投注。
   - **成交当下若该券已过期或已无剩余次数，此预约单状态变更为失败**（注单页 Expired · `Booking failed`）。

| 输赢金额 | **仅计入赢的部分**：用券注单赢 → 以**总派彩金额**（券面额 × 赔率）计入；赢半 → 以派彩金额（券面额 ÷ 2 × 赔率＋券面额 ÷ 2）计入；用券注单输、输半 → 不计入（视为 0） |

> **范例：**今日篮球有 2 笔用券注单——A 用 ₱100 券 @7.40 赢、B 用 ₱500 券输。
> - 投注区：「投注次数」+2、「投注人数」含 A、B；「投注金额」**不含**这 600，「免费投注」＝ `600`。
> - 已结算区：有效投注数／人数／金额、今日结算注单总投注额、会员输赢（不含退水、免费投注）、会员盈利率皆**不含** A、B；今日结算注单**含** A、B（+2 笔）。
> - 输赢金额：**只计 A**（赢），以总派彩 `100 × 7.40 = 740` 计入；B（输）不计入。

## 判断逻辑

*下注判断 · 预约扣次 · 券可用判断 · 券清单排序*

#### 用券下注判断流程

```
开启 SportsVoucher
  └ 未选券 → Place Bet 反灰不可点
  └ 选券后，会员择一操作：
     操作 A · 一般投注
       1. 直接点击 Place Bet
       2. 处理中 `The order is being processed......`
       3. 成功 → 扣 1 次（剩 0 → 从清单移除）
          失败 / 赔率已变 → 不扣（可 Accept and bet 重送）
     操作 B · 预约投注
       1. 点击 + Booking，设定预约赔率
       2. 预约赔率 < 当前赔率 → 预约栏红框＋红字，Place Bet 反灰不可点
          （调整为预约赔率 ≥ 当前赔率后才可点）
       3. 点击 Place Bet → 预约成功（不扣次、不锁次）→ Scheduled
       4. 预约赔率匹配成功当下：
          券未过期且剩余 ≥ 1 → 扣 1 次、成交 → Unsettled
          已过期或剩余 0 → 预约单失败 → Expired · Booking failed
```

| 开启 | OUTRIGHTS | — | — | — | 栏位反灰不可点 |
| 开启 | ENDING CARD／ENDING GAME／串关 | — | — | — | 无此栏位 |
| 开启 | 单关 | 是 | 任意 | — | 体育投注页不显示 |
| 开启 | 单关 | 否 | 0 | — | 不显示（已用完） |
| 开启 | 单关 | 否 | ≥ 1 | 否 | 显示、反灰不可选，排最后 |
| 开启 | 单关 | 否 | ≥ 1 | 是 | 显示、可选，计入 n available |

#### 边界与异常

| 情境 | 处理 |
|---|---|
| 已成交的用券注单被取消／作废 | 注单显示 `Bet Cancellation`；会员获得**一张新券**（1 次、同面额、有效期自退回起算）；后台新增一笔「注单退回」记录 |
| 券在投注页开着时到期 | 倒数至 `00:00` 即自动从清单移除（已选则取消选择），`n available` 同步减少 |
| 用券注单结算 · 赢 | 派彩＝券面额×赔率入余额；Win/Lose 显示总派彩 |
| 用券注单结算 · 输 | 无派彩；Win/Lose 显示 0.00 |
| 用券注单结算 · 赢半 | 仍消耗 1 次；派彩＝券面额 ÷ 2 × 赔率＋券面额 ÷ 2（例 ₱100 @1.90 → 145）；Win/Lose、后台输赢金额皆显示派彩金额 |
| 用券注单结算 · 输半 | 仍消耗 1 次；不退回金额、不补券；Win/Lose 显示 0.00；后台输赢金额 0.00 |
| 余额为 0 | 仍可用券下注 |
| 后台球类报表 · 用券注单 | 投注区：计入投注次数、投注人数、「免费投注」；不计入「投注金额」；已结算区：不计入有效投注数／人数／金额、今日结算注单总投注额、会员输赢（不含退水、免费投注）、会员盈利率；今日结算注单：计入；输赢金额：只计用券赢的注单，以总派彩金额计入。 |
| 后台体育注单 · 用券注单 | 备注栏另起一行显示 `SportsVoucher`；画面输入金额／下注金额＝券面额；有效下注金额 `0.00`；输赢金额：赢、赢半＝派彩金额；输、输半＝`0`。 |
| 编辑券配置 | 已发出的券不变；之后发出的是新券 |
| 删除券配置 | 不可再赠送；已发出的券可用到期 |
| 优惠券系统开关关闭→开启 | 体育投注页 SportsVoucher 栏位隐藏 → 恢复显示；期间券有效期照常计算 |
