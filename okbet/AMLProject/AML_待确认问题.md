## A. 红旗规则定义（影响规则引擎，优先确认）

| # | 问题 | 建议默认 |
|---|---|---|
| A1 | 重复账户的触发时机：PDF 写「KYC 验证通过时」，原型写「注册或登录时」。旧玩家要不要上线时全量比对一次？ | KYC 通过时比对；上线时全量比对一次 |
| A2 | 重复账户的比对字段：设备、IP 要不要算？（配置页只有开关，字段固定，需先定案） | 证件号码、银行／支付账户、姓名＋出生日期、手机、邮箱；设备、IP 不算 |
| A3 | 重复账户的命中条件：哪些单项相同就命中、哪些要组合？ | 单项：证件号码、银行／支付账户；组合：姓名＋出生日期 |
| A4 | 比对范围含已冻结、停用、注销的账户吗？ | 包含 |
| A5 | NDRP 筛查频率：每次登录或每 7 天？（配置页没有此设置，由系统固定） | 每次登录，同一玩家 24 小时内只查一次 |
| A6 | NDRP API 由谁提供、是否已接？现有「NDRP标签」30 人是怎么打上的？ | 需开发方确认 |
| A7 | API 回传「可能命中」怎么处理？ | 不冻结，产生告警 |
| A8 | NDRP 冻结用「冻结」还是「ndrp冻结」状态？ | ndrp冻结 |
| A9 | 「6 个月」按日历月还是 180 天？ | 日历月 |
| A10 | 休眠存款只算激活当天吗？（例：当天 ₱150,000、隔天 ₱100,000 是否触发） | 只算当天，此例不触发 |
| A11 | 用赠金／免费投注算不算「有投注」？ | 只算真钱投注 |
