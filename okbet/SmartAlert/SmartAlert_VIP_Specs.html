1 需求目的
目的说明
  • 建立一套「智能推播」机制：依后台设定的VIP 等级与触发条件（账户余额、有效投注、用户负盈利），在符合资格时于前台首页弹出「活动快报」弹窗。
  • 弹窗内含两大区块：待领取奖励（导流至对应活动）与福利加码（直接发放后台配置的奖励）。
  • 后台提供新增／编辑／删除推播条件、总开关、以及推播列表（见 3.3）与推播记录（见 3.4）。
  • 既有的免费项目记录与优惠券记录页面，来源筛选新增「推播奖励」选项，用于追踪由推播发出的奖励（异动）。
ℹ
本文拆分为「前台（第 2 节）」与「后台（第 3 节）」，每一功能区块以「图 + 文」呈现。 凡涉及判断／状态切换／多选项组合之规则，统一在第 4、5 节以表格穷举，第 6 节列出变更分类与本次未涉及之既有规则。

显示位置（对应规则 B）
  • 推播弹窗仅在「首页」显示；离开首页（进入三方游戏页、个人中心等）一律不显示。
  • 首页涵盖以下 tab，任一 tab 皆属首页范围：Popular、OKWIN、Slot、Perya、Casino、Poker、Arcade、E-Bingo、Numeric。
风控名单排除（一律不显示）
  • 当用户账号出现在后台「风控黑名单」或「NDRP 名单」清单时，一律不显示推播弹窗。
  • 此为最优先的排除条件：命中任一名单即直接结束，不再判断资格、优先顺序或每日次数。
  • 名单以触发当下（时机 A）的即时状态为准；触发后才被移出名单者，需下一次触发时机才可能显示。
弹窗结构与文案
  • 标题固定文案：「活动快报」（不可变动，翻译编号：T0290）。
  • 弹窗视觉依「EVENT BULLETIN」图例呈现：顶部吉祥物标题栏、活动以横版底图卡呈现、加码卡带「BONUS+」标记（相关素材见附档，样式参考原型互动示意）。
  • 由上而下：标题 → 待领取奖励区（清单）→ 加码奖励卡片；「福利加码」不另设小标题，改以加码底图右上红色角标显示。
  • 弹窗高度固定；当待领取奖励清单过多时，仅清单区可上下滑动，其余区块不随之滚动。
  • 右上角提供关闭（✕）；点击关闭当次不再显示（当日再次触发的判断见规则 D）。
  • 待领取奖励(翻译编号：T0291)，显示对应活动横版Banner；仅显示有「未领取」奖励的活动。
  • 福利加码(翻译编号：T0292)，显示奖励icon及奖励内容；仅「礼金」需额外显示流水倍数。
  • 流水倍数(翻译编号：A077、B292)，依后台配置显示对应标目值，数值为空或0即不显示此文提示。
文案长度限制
  • 「活动名称」最多一行显示，超过即以省略号...呈现。
  • 「奖励文案」最多一行显示，超过即以省略号...呈现。
  • 「福利加码」红色角标上的文案，完整显示。
  • 「领取 (翻译编号：A038)」按钮文案固定 2 字，靠右不换行。
情境（对应第 5 节穷举）
  • 情境①：待领取奖励 + 福利加码　｜　情境②：仅待领取奖励　｜　情境③：仅福利加码。
  • 两区块皆无内容时不触发弹窗（不显示空窗）。

⚠

3.2.1 基本信息
  • 推播名称：必填，最长 50 字。
  • 编辑模式下推播名称不可变更（栏位置灰、不可编辑）。
3.2.2 推送目标用户（下拉/标签来源）
  • VIP 等级：单选、必填；来源固定 11 项：VIP 0 ~ VIP 10。
  • 再次点击已选项＝取消选取。
3.2.3 触发条件（输入框限制 · 规范 3.1.6）
  • 账户余额：必填、单一目标值、不分阶级；判断为「小于等于（≤）目标值」；不可为 0 或负数。
  • 有效投注（≥）、用户负盈利（≥）：选填、可依阶级各自设置；留空＝该阶不启用此条件；不可为 0 或负数（输入负号自动去除）。
  • 最多 10 阶；「新增阶级」为共用按钮，两项条件同步增减阶级。
  • 递增校验：下一层目标值不可小于上一层。
3.2.4 推送奖励（每阶，下拉来源）
  • 阶级数与触发条件共用（在触发条件区新增／删除阶级）。
  • 活动推送：勾选「推送角标相关活动」才推送；限角标活动：盈利活动 / 消费活动 / 每日特别返水 / 每日特别加码 / 游戏挑战赛。
  • 奖品类型（选填，下拉）：礼金 / 积分 / 免费旋转 / 免费投注 / 优惠券。
  • 礼金、积分 → 输入数量；礼金另需输入「所需流水倍数」。
  • 免费旋转 / 免费投注 / 优惠券 → 下拉选奖品内容（来源：JILI／FKG／FC；ONlive／Mini；20%／10% Loss Cashback、10% Deposit Voucher 等）。
  • 每个阶级的「活动推送」与「奖品类型」至少需择一配置，不可两者皆空（此为红字提示，显示于推送奖励区）。

失败提示（规范 3.1.3；字段标红 + 下方红字）
